# Qamar Zaman — Full-Stack .NET Developer Portfolio

Open `index.html` to view the site. No package installation or build is required. Fully responsive dark theme with red accent color.

## Features

### Sections
- **Hero Section** — Full-stack .NET developer introduction with animated resume dropdown (View Online + Download)
- **About Section** — Professional summary with experience stats
- **Experience Section** — HisabDo Internship, Codomax Internship, and Freelance experience timeline
- **Tech Stack** — Visual grid of 10+ technologies with icons
- **Skills Section** — Animated progress bars showing 16+ proficiencies
- **Projects Section** — 11 projects with 4-image gallery and lightbox viewer with keyboard navigation
- **Certification Section** — Professional certifications and courses
- **FAQ Section** — Common questions about .NET development
- **Contact Section** — Social cards (LinkedIn, Facebook, GitHub, WhatsApp, Gmail) and contact form

### Interactive Features
- **Scroll Progress Bar** — Red progress bar at top tracks scroll position
- **Project Filter Buttons** — Filter projects by .NET, Angular, MVC, Web API
- **Back to Top Button** — Floating button appears on scroll
- **Lightbox Viewer** — Click any project image to view gallery with arrow navigation
- **Resume Dropdown** — View online or download resume
- **Custom Cursor** — Animated custom cursor with ring effect
- **Scroll Reveal Animations** — Sections animate in on scroll
- **Mobile Responsive** — Fully responsive on all devices

## Social Profiles

Edit `assets/site-config.js`:
- `linkedin`: Your LinkedIn profile URL
- `facebook`: Your Facebook profile URL
- `github`: Your GitHub profile URL
- `whatsapp`: Your WhatsApp number (with country code)
- `email`: Your preferred contact email

## Adding Project Images

Place project screenshots in `assets/projects/` folder:
- `{project-name}-1.jpg` through `{project-name}-4.jpg`
- `{project-name}-1` through `{project-name}-4` for each project

Update `data-gallery` attributes in `index.html` to match your project names.

## Adding Resume

Place your resume PDF at `assets/resume-qamar-zaman.pdf` or update the download link in the hero section.
