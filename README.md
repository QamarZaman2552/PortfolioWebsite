# Muhammad Shahzaib — Full-Stack .NET Developer Portfolio

Open `index.html` to view the site. To publish, upload the contents to any static host, keeping the `assets` folder beside the HTML pages. No package installation or build is required.

## What's Included

- **Hero Section** — Full-stack .NET developer introduction with resume download
- **About Section** — Professional summary with experience stats
- **Tech Stack** — Visual grid of technologies (ASP.NET Core Web API, ASP.NET Core MVC, Angular, SQL Server, JWT, TypeScript, HTML/CSS/JS)
- **Skills Section** — Animated progress bars showing proficiency levels
- **Projects Section** — Featured projects with video demo support
- **FAQ Section** — Common questions about .NET development services
- **Contact Section** — Social cards (LinkedIn, Facebook, GitHub, WhatsApp, Gmail) and contact form

## Social Profiles

Edit `assets/site-config.js`:

- `linkedin`: Your LinkedIn profile URL
- `facebook`: Your Facebook profile URL
- `github`: Your GitHub profile URL
- `whatsapp`: Your WhatsApp number (with country code)
- `email`: Your preferred contact email

## Adding Project Videos

Place your project demo videos in `assets/videos/` folder:
- `project-demo-1.mp4`
- `project-demo-2.mp4`
- `project-demo-3.mp4`
- `project-demo-4.mp4`

Update the video sources in `index.html` to match your actual video files.

## Adding Resume

Place your resume PDF at `assets/resume-muhammad-shahzaib.pdf` or update the download link in the hero section.

## Technologies Used

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Bebas Neue, Outfit)
- No frameworks or build tools required
- Fully responsive design
- Dark theme with red accent color

## Validation

- All HTML pages: local file references and linked anchors checked
- All images: files decode, alt text present
- All inline JavaScript blocks pass syntax checks
- Desktop and mobile responsive layout verified
